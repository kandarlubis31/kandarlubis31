# kandarlubis31 — Project Context

## Ringkasan

Repo khusus **profil GitHub**. Tidak ada aplikasi atau build di sini: GitHub menampilkan `README.md`
repo ini di halaman profil, jadi seluruh isinya adalah markup.

Isi profil: ringkasan singkat, keahlian, proyek unggulan, dan tautan kontak. Proyek yang dipamerkan
diambil dari repo lain, bukan dari kode di repo ini.

## Aturan penyuntingan

- Nama repo harus `kandarlubis31` dan README harus di root — hanya dengan begitu GitHub memasangnya
  sebagai profil.
- Tidak ada proses build, test, atau deploy. Setiap perubahan langsung tampil setelah di-push ke
  branch default.
- Gambar sebaiknya WebP/PNG terkompresi dan disimpan di repo (atau CDN), karena README dimuat setiap
  kali profil dibuka.
- Tautan ke repo lain harus publik; tautan ke repo privat akan mati bagi pengunjung.

## Struktur

```
README.md    Isi profil (satu-satunya berkas yang tampil)
```

## Catatan

- Ada juga salinan lokal di `Project/github-profile/kandarlubis31`; sinkronkan setelah menyunting.
- Badge dinamis dari layanan pihak ketiga bisa gagal dimuat; jangan jadikan satu-satunya penanda
  status penting.
